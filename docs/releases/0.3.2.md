# Victual 0.3.2

**Tag `v0.3.2`, on `master` at the commit that merges this record.** It follows
[0.3.1](0.3.1.md). It is a patch version because it adds no migration and changes no route
or wire format. It adds one capability: the InfluxDB event writer speaks InfluxDB 1.x and
3.x as well as 2.x.

## What changed

| Change | Effect for an operator |
|---|---|
| **`INFLUXDB_VERSION` (`1`, `2` or `3`; default `2`)** selects the write endpoint and authentication. | An existing 2.x deployment changes nothing. 1.x writes to `POST /write?db=` with basic authentication (`INFLUXDB_USERNAME` and `INFLUXDB_TOKEN` as the password); 3.x writes to `POST /api/v3/write_lp?db=` with a Bearer token. |
| **`INFLUXDB_BUCKET` is the database on 1.x and 3.x**; `INFLUXDB_ORG` is required on 2.x only. | A 1.x database must exist before enabling (`CREATE DATABASE victual`). Point at a database of its own, not Home Assistant's. |
| **The Helm chart gains `influxdb.version` and `influxdb.username`.** | The schema refuses a version other than 1, 2 or 3, and an empty `org` on 2. `deploy/k3s/` is unchanged apart from image tags. |
