# Victual 0.5.1

**Tag `v0.5.1`, on `master` at the commit that merges this record.** It follows
[0.5.0](0.5.0.md). It is a patch release: two compatible fixes on error paths, the evidence for
release gate R5 that 0.5.0 lacked, corrected restore steps, and test and record maintenance.
The [0.5.1 release dashboard](../../release-planning/2026-10-19/dashboard.md) tracks its eight
issues, all closed.

## What changed

| Change | Effect for an operator or client |
|---|---|

## Database migrations

None. The only change under `migrations/` since `v0.5.0` is a path inside a comment in
`0292.pgsql.sql` (PR 1005). The migrator does not fingerprint migration files, so an
installation that applied 0292 is unaffected. 0.5.1 expects the schema 0.5.0 left, at
migration 318.

## Compatibility

- **Accepted input:** a consume `recipe_id` must name an existing recipe (above). A client that
  sent `0` or a negative id to mean "no recipe" now gets 400 and should omit the field instead.
- **Response shapes:** only the calendar feed's 500 body changes. No success response changes.
- **Permissions, configuration and deployment paths:** unchanged. The images, chart values and
  manifests change only in their version.

## Known limitations

- **Restore drill scope.** The drill used `FILE_STORAGE` `database` only. The manual's
  storage-directory step for `filesystem` was not exercised. Label, MQTT and InfluxDB traffic
  and restores across versions were not drilled either; the record lists each gap.
- **An upload with a form content type stores an empty file.** `PUT /api/files/{group}/{name}`
  sent with `application/x-www-form-urlencoded` instead of the documented
  `application/octet-stream` stores 0 bytes and answers 204. The drill found it, and 0.5.1 does
  not change it.
- **Gate R6** (a production support claim for cluster labels and shutdown) stays unplaced: 0.5.1
  makes no cluster label or shutdown support claim.
- The `CanonicalJson` and `StderrLogger` fallbacks that coverage marks as unreachable stay until
  each has a per-PHP-version proof (issue 1026, 0.5.2).
