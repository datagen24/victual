# Victual 0.4.4

**Tag `v0.4.4`, on `master` at the commit that merges this record.** It follows
[0.4.3](0.4.3.md).

## What changed

| Change | Effect for an operator or client |
|---|---|
| Renderer claim ticks signal `db-changed-time` when they reap or claim work ([PR 973](https://github.com/datagen24/victual/pull/973), issue 898). | Clients can refresh after a claim tick changes visible state. Empty polls remain no-ops, and the response contract is unchanged. |
| Artifact storage and preview collection are serialized ([PR 972](https://github.com/datagen24/victual/pull/972), issue 926). | Concurrent collection cannot remove an artifact while its storage operation is completing. |
| Published artifact references for 0.4.3 were added to its release record ([PR 971](https://github.com/datagen24/victual/pull/971)). | Documentation only; no runtime effect. |

The release adds no database migration, permission, configuration, or deployment-path
change. It preserves response shapes and accepted inputs.
